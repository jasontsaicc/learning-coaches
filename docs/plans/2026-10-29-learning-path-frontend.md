# Learning Garden 學習路徑：前端設計規劃

狀態：第一版已實作並重建本機網站；以下為設計規格。配合 [SD / k8s 課程藍圖](2026-10-29-sd-k8s-learning-path.md)。

## 設計方向

使用已安裝的 `design-taste-frontend`，依 `references/app-screens.md` 的 app 流程規劃。
抽選方向為 **Achromatic ledger**，seed `733347970`，保留現有 palette/type。
候選另一方向為 Editorial greeting；本頁主要是選課、查找與閱讀，不需要 greeting 成為視覺主角。
Shell 重抽一次：Open plane → No sidebar。原因：現有網站目的地少、已有頂部導覽；額外加入全站側欄會擴大這次課程頁改動。

核心問題：**我現在要學哪個單元，點哪裡能讀到筆記？**

產品特徵：將 SD 的問題驅動隊列與 k8s 的機制依賴，呈現為「可展開的課程目錄」。目前位置是唯一主要色彩訊號；教材齊備度與學習進度用文字分別表達。

## 真實資料與主要工作

1. 使用者是持續學習 SD/k8s 的個人，會在桌面選課、手機複習。
2. 主要物件是 course、phase、node、chunk、HTML note、既有章節練習。
3. Phase 表達範圍，node 表達大問題，chunk 表達可驗收目標。
4. SD 待學隊列有八章，排序取自 10-29 方案 B；不能依 Day 大小排序。
5. k8s 自動伸縮有 HPA→VPA→KEDA→節點供給的具體前後關係。
6. 教材有專題、共用、部分、待補；例如 KEDA 現有頁只到機制段。
7. 學習狀態由 progress 提供；讀過 HTML 不代表通過 gate。
8. 最近閱讀是瀏覽器本地狀態，不能冒充 coach 的目前進度。
9. 最常見工作是直接開啟一個 chunk 的 HTML，其次是展開另一個 node。
10. 練習、知識地圖、記憶卡保留入口，課程選擇不必經過它們。

## 第一屏與桌面版面

保留 Learning Garden 名稱、首頁與搜尋。課程頁取消大幅插圖與英文 eyebrow，h1 改為 24–28px 的課程名稱。插圖仍可留在首頁課程卡，不占課程頁第一屏。

桌面內容最大寬 1120px，左右對稱；1440px 視窗為 `160 + 1120 + 160`。
課程目錄採單欄，node 標題、狀態與子單元沿固定欄位對齊，不增加預覽右欄。
展開後 chunk 的學習目標填入第二行，避免長列只剩標題與遠在右端的狀態。

首屏優先顯示課程名稱、目前單元入口、當前 phase 與至少一個展開 node。完整課程保留在同一頁；phase 選擇器只是跳到該分區，不隱藏其他階段，也不加入第二層 accordion。

## Node / chunk 互動契約

| 元件 | 行為 |
|---|---|
| Node 左側箭頭 | 獨立 button，控制子清單；`aria-expanded` / `aria-controls`，命名如「展開自動伸縮」 |
| Node 標題 | 有 hub 或指定主題頁才為 link；沒有則為普通文字，箭頭仍可操作 |
| Chunk 標題 | 指向顯式配置的 HTML 或 fragment；沿用現有另開分頁，附 ↗ 與可存取的新分頁提示 |
| Chunk 第二行 | 一句可驗收的學習目標；不用 Day/C 編號代替內容 |
| 目前位置 | 由正式進度對照到 node/chunk；無法精確對照時只標 node，不猜 chunk |
| 開啟目前筆記 | 僅在能確定目標且有 HTML 時顯示；無 HTML 時改為「定位目前單元」，跳到清單中的缺口 |
| 最近閱讀 | 有本地紀錄時提供次要「上次讀到」連結，與正式目前位置分開 |
| 展開／收合 | 允許同時開多個 node；初次進入只自動展開目前 node，無對照則開第一個；本次頁面返回保留展開與捲動位置 |
| 其他筆記／練習 | 同 node 有多份筆記時以次要連結列出；練習顯示於對應 node 的收尾，保留既有題庫 ID |

DOM 使用 section / h2 / article / h3 / ol，button 與 anchor 為兄弟元素；不把 link 包進 button，不使用需要完整方向鍵模型的 ARIA tree。
Chunk 整列不加第二份 click handler，避免點到補充連結也開主教材。
主題切換不觸發自動開新分頁，使用者必須點閱讀連結。

## 狀態文案

| 資料狀況 | 呈現 |
|---|---|
| 有 HTML、未評量 | 「教材：專題筆記」「學習：尚未評量」分列；不顯示完成勾號 |
| 只有部分內容 | 「部分教材」，可點既有 HTML；第二行指出缺口 |
| 多個 chunks 共用頁面 | 「共用筆記」；只有確認存在且符合內容的 fragment 才深連 |
| 沒有 HTML | 「待補 HTML」文字；標題不做假連結，不給無效的閱讀按鈕 |
| 有練習但無正式評分 | 沿用現有「已練習 · 尚無章節評級」；不把練習當正式 gate |
| FLEX / 陌生題池 | 在主線之後獨立分區，文字標「選修」或「mock 抽題」；不加鎖、不算主線欠課 |
| 課程資料載入中 | 保留標題與載入提示；不先顯示「沒有課程」 |
| 載入失敗 | 顯示錯誤及重試；不要呈現空清單或捏造進度 |
| 本地閱讀紀錄不可用 | 路徑與 HTML 仍可用；只對最近閱讀功能說明限制 |

先不顯示課程完成百分比：node/chunk 尚未全部有可對應的正式評量，分母沒有可靠定義。

## 視覺規格

保留 Public Sans + Noto Sans TC；Share Tech Mono 只沿用於程式碼，不用於課程標籤。
取既有品牌色作語意映射，課程頁減少裝飾面積；不全站替換 CSS tokens。

| 角色 | 規格 |
|---|---|
| 背景／表面 | 低彩度 `#f4f5f2` / `#ffffff`；用微小色階及淡分隔線組織清單 |
| 主文字／次文字 | `#243a32` / `#59655e`；實作後確認各背景上的 4.5:1 對比 |
| 目前位置 | 品牌綠 `#315f47` 的小點與「目前單元」文字；不染整列、不只靠顏色 |
| 主按鈕 | 深墨色底、白字；每屏最多一個填色主按鈕 |
| 字級 | h1 28/手機24；phase 20；node 18；chunk 16；說明與狀態14 |
| 行高／間距 | 中文正文1.6；node 內距16；chunk 最小高度64，長字自然增高；phase 間距32 |
| 圓角 | 區塊8、控制6；列表不每列套卡片，不加靜態陰影 |
| 操作尺寸 | 展開按鈕及手機觸控區至少44×44；focus ring 清楚可見 |
| 動效 | 箭頭旋轉約120ms；不做載入飛入、長高度動畫或自動平滑追焦；reduced-motion 關閉轉場 |

不新增圖表、裝飾連線或圖片。既有 D3 知識地圖保留為輔助入口；主路徑是可掃讀的目錄。

## 平板與手機

- 768px：24px 邊距，單欄主路徑，工具連結可自然換行。
- 390px：16px 邊距，內容寬358px；若扣44px箭頭與8px間距，node 標題有306px。
- Chunk 只縮排16px；狀態移至標題下方，不和中英長標題搶一行。
- 保留課程名、目前單元入口與一行 phase 選擇器；第一個 node 應在手機首屏上方60%內出現。
- Phase 不做八個橫排標籤；使用有 label 的原生 select 跳轉，避免整頁水平溢出。
- 點筆記仍另開分頁；回原頁保持展開與捲動位置。
- 長標題允許換行，不以省略號藏掉辨識主題的字；純技術長字可 `overflow-wrap`。

2. Arrow/link 各自工作；鍵盤可展開、閱讀及返回；關閉 node 不讓焦點留在隱藏內容。
3. 1440/768/390 三種寬度的截圖，含展開、收合、缺教材、長標題與載入錯誤。
