## 1. 變數等於貼標籤,不是數學等號

**白話:** `a = b` 不是「a 和 b 永遠相等」,是「把 a 這張標籤,貼到 b 現在指的那個東西上」。
貼完之後 b 再變,a 不會跟著變。

```
a = 5          標籤 a  ──→ [5]
b = a          標籤 b  ──→ [5]      兩張標籤貼在同一個 5
a = 9          標籤 a  ──→ [9]      a 改貼到 9
                標籤 b  ──→ [5]      b 還在原地
```

**30 秒手算:** 上面跑完,`b` 是多少?答案 `5`。如果是數學等號,b 會變成 9。

**對應常犯錯:** 這是概念 5(迴圈變數每圈重算)的基礎。

---

## 2. `/` 給小數,`//` 給整數。index 只吃整數

**白話:** `/` 一律回 float,就算除得盡也是。`//` 回整數。list 的索引只吃整數,
給 float 直接報錯,不會自動轉。

```
7 / 2   →  3.5     (float)
6 / 2   →  3.0     (float,除得盡也是 float)
7 // 2  →  3       (int)

nums[3.0]  →  TypeError: list indices must be integers
```

**30 秒手算:** `mid = (0 + 4) / 2` 之後 `nums[mid]` 會怎樣?
答案:`mid` 是 `2.0`,`nums[2.0]` 直接 TypeError。要寫 `//`。

**口訣:** 算索引、算中點,一律 `//`。

**對應常犯錯:** checklist 第 2 列(犯過 2 次)。

---

## 3. list 的方法名

**白話:** Python 的 list 沒有 `.push`,加東西到尾巴是 `.append`。

```
nums = [1, 2]
nums.append(3)   →  [1, 2, 3]      加到尾巴
nums.pop()       →  拿走尾巴的 3,list 變 [1, 2]
nums[-1]         →  看尾巴是誰,但不拿走
len(nums)        →  幾個元素
```

**30 秒手算:** `stack = []` 之後 `stack[-1]` 會怎樣?
答案:`IndexError`,空的沒有尾巴。所以取 `[-1]` 前要先確認不是空的。

**對應常犯錯:** checklist 第 6 列、第 8 列。

---

## 4. 縮排等於這行屬於誰

**白話:** 縮排不是排版,是在講「這行歸誰管」。歸迴圈管的每圈做一次,歸函式管的做一次。

```
def f(nums):          ← 歸函式管
    for n in nums:    ← 歸函式管,做一次
        print(n)      ← 歸迴圈管,每圈做一次
        return n      ← 歸迴圈管 → 第一圈就跑掉了
    return 0          ← 歸函式管,迴圈跑完才做
```

**30 秒手算:** `f([7, 8, 9])` 回傳什麼?
答案 `7`,因為 `return n` 在迴圈裡,第一圈就結束了。把 `return n` 往左退一格,答案變 `0`。

**判準(自己講得出來才算會):** 問「這個動作該做幾次?」每圈一次就在迴圈內,
跑完做一次就在迴圈外。

**對應常犯錯:** checklist 第 1 列(`return` 縮排卡在迴圈裡,犯過 3 次,最貴的一種。
症狀是找得到的全掛、找不到的全綠,而且不報錯)。

## 5. 迴圈變數每一圈重新求值

**白話:** 迴圈裡的每一行,每一圈都重新跑一次。`nxt = curr.next` 不是算一次就固定,
是每圈依照當下的 `curr` 重新算。

```
curr = 1 → 2 → 3

第 1 圈   curr 站在 1,  nxt = curr.next = 2
第 2 圈   curr 站在 2,  nxt = curr.next = 3     ← 重算,不是還是 2
第 3 圈   curr 站在 3,  nxt = curr.next = None
```

**30 秒手算:** 第 2 圈的 `nxt` 是誰?答案 `3`。答成 `2` 就是把上一圈的值帶過來了。

**問法(每次都要這樣問):**「這行在第 k 圈執行時,值是誰?它依賴什麼?」

**對應常犯錯:** 觀念表第 1 列(「這行什麼時候被求值」,4 次跨題)。

## 6. `while X:` 的 X 是「還要不要再跑一圈」

**白話:** `while` 後面填的是**繼續的條件**,不是**結束時的樣子**。這兩個剛好相反。

```
while l <= r:      ← X 為真 → 再跑一圈
    ...
                   ← X 為假 → 跳出來,此時 l > r

填的是  l <= r        (繼續條件)
不是    l > r         (結束狀態)
```

**30 秒手算:** `l = 0, r = 2`。`while l <= r` 會跑幾圈(每圈 `l += 1`)?
答案 3 圈(l=0,1,2),第 4 次檢查時 l=3 > r=2,跳出。

**問法:**「X 為真的時候程式在做什麼?為假的時候在做什麼?」

**對應常犯錯:** 觀念表第 1 列的第二個症狀。

## 7. node、pointer、`.next` 等於火車廂

**白話:** 一個 node 是一節車廂,裡面有貨(`.val`)和一個掛鉤(`.next`)指向下一節。
所謂 pointer 就是「你現在站在哪一節車廂」。

```
head
 ↓
[1|•]──→[2|•]──→[3|•]──→ None
 ↑  ↑
 val next

curr = head        你站在第 1 節
curr = curr.next   往後走一節,現在站在第 2 節
curr.next = prev   改掛鉤,讓這節改指向 prev。原本的下一節就找不到了
```

**關鍵:** `curr = curr.next` 是**你移動**;`curr.next = X` 是**改掛鉤**。
兩個長得像,做的事完全不同。改掛鉤之前要先把原本的下一節存起來,否則走不回去。

**30 秒手算:** `[1|•]──→[2|•]`,執行 `curr.next = None` 之後,還找得到 2 嗎?
答案:找不到了,除非之前有另一張標籤指著它。

**對應常犯錯:** Linked List 整個 pattern 的基礎。#206 的 `nxt = curr.next` 就是在做這件事。
