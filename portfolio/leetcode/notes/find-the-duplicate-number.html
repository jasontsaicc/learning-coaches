Find the Duplicate Number

One number shows up twice. Find it without touching the array.

What you get

A list of n+1 numbers. Every number is between 1 and n. One of them repeats.

Why a repeat must happen

6 birds. 5 holes. Somebody shares.

鴿籠原理 (pigeonhole principle)：東西比格子多，就一定有格子裝到兩個。

The easy way

Keep a bag of numbers you saw. The first number already in the bag is the answer.

def findDuplicate(nums):
    seen = set()
    for x in nums:
        if x in seen: return x
        seen.add(x)

Fast, simple, and it fails the follow-up: the bag can hold n numbers. That is O(n) extra space.

Hard mode

Two rules

Do not change the arrayno sorting, no marking
Use O(1) extra spaceno set, no count array

So you get a few variables. Nothing else.

Trick: the array is a chain

Read a box like a street sign: you are at index i, go to index nums[i].

Every index has exactly one arrow out. So the walk never stops. With n+1 boxes and only n possible targets, the walk must come back to a place it already visited.

值都在 1..n，所以永遠走不到 index 0；走出去就回不來，一定形成 cycle。

The duplicate is the door

Two boxes hold the same value. So two arrows land on the same index. That index is where the loop starts.

→ find the door, and you have the duplicate

How to find the door

Two walkers. 🐢 takes 1 step. 🐇 takes 2 steps. Inside a loop the fast one catches the slow one.

Then send 🐢 back to the start. Now both take 1 step. They meet at the door.

🐢 one step 🐇 two steps
Both start at index 0.

The code

def findDuplicate(nums):
    slow = fast = nums[0]
    # phase 1: let them meet inside the loop
    while True:
        slow = nums[slow]
        fast = nums[nums[fast]]
        if slow == fast: break
    # phase 2: walk together to the door
    slow = nums[0]
    while slow != fast:
        slow = nums[slow]
        fast = nums[fast]
    return slow

Remember this

Values in 1..n over n+1 slots is the signal. It means the array is a chain with a loop, and the loop door is the repeat.
