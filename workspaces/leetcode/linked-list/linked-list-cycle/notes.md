## 這題的重點

- 快慢指標換掉的是**空間** O(n) -> O(1),**時間一樣**是 O(n)。講成「比較快」是錯的。
- invariant:兩者都進環後,差距每圈剛好減 1;非負整數每次減 1 不可能跳過 0,所以必相遇。
- **更正(2026-09-10,原本這裡寫錯):** 兔子走 3 步「跳過 0 所以抓不到」是錯的。
  差距是在**環上取模**,不是在數線上遞減。步長 s 時差距每圈變化 (s-1),
  要相遇只需 (s-1)*k ≡ 0 (mod L),取 k = L 永遠有解 -> **任何 s >= 2 都抓得到**。
  模擬驗證(m=0..11, L=1..12):s=2/3/4 漏抓 0 組。s=3 通常還更快(m=3,L=6:s=2 要 6 圈,s=3 只要 3 圈)。
  用 2 的真正理由:(a) 最小可行、`while` 只需檢查 2 格;(b) **#142 找環入口的推導依賴 fast = 2*slow 這個比例**,
  改成 3 就不成立。
- `while fast and fast.next`:跳幾格就要檢查幾格。順序不能反(短路求值)。
- 比指標用 `is` 不用 `==`,值可以重複、身分不會。
- `return False` 必須在 while 外面(學員常犯錯第 1 名)。
