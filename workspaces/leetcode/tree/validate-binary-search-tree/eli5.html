兩張紙條的 BST

Validate Binary Search Tree。#1448 傳一張紙條(路上最大值),這題傳兩張:low 和 high。

01這題在幹嘛

檢查一棵樹是不是 BST。規則:左邊整棵都比我小,右邊整棵都比我大。相等不行。

重點是「整棵」,不是只看小孩。用這棵樹,整頁都用它:

node只看爸爸看整條路上的祖先
44 < 5 ✓4 < 5 ✓
66 > 5 ✓6 > 5 ✓
33 < 6 ✓3 < 6 ✓,但要 3 > 5 ✗
77 > 6 ✓7 > 6 ✓,7 > 5 ✓

02這是什麼型

  • 1答案跟祖先有關(3 要跟 5 比)→ 由上往下走,前序 + 往下傳值。跟 #1448 同一招。
  • 2每站需要知道的是一個範圍:比誰大、比誰小 → 傳兩個參數 low、high。
  • 3跟 #1448 不一樣的地方:這個函式交回 True / False,不是數數量。所以不用 res list,用 return 交回去。

03直覺的錯法,和暴力法

錯法:只跟小孩比

每站檢查 node.left.val < node.val < node.right.val。01 那棵樹每一站都過,會回 True,但答案是 False。它漏掉的是 3 和祖父 5 的關係。

暴力法:每站掃整棵子樹

每個 node 都去找「左邊整棵的最大值」和「右邊整棵的最小值」來比。對,但每站都要重掃一次子樹。

每站掃整棵子樹往下傳 low / high
每站做什麼掃子樹全部 node比 2 次
時間O(n²) 最壞(一條線的樹)O(n)
空間O(h)O(h) call stack

暴力法浪費的事:祖先的值一路上都看過了。把「我要比誰大、比誰小」寫在紙條上交下去,小孩就不用回頭掃。

def isValidBST(self, root):

    def dfs(node, low, high):                 # 兩張紙條
        if not node:
            return True                        # 空樹算合法
        if not (low < node.val < high):        # ① 判斷自己            return False        return (dfs(node.left, low, node.val) and   # ② 往左:high 換成我                dfs(node.right, node.val, high))     #    往右:low 換成我
    return dfs(root, float("-inf"), float("inf"))
行做什麼
return True走到 None 交回 True。交回型別要跟下面一樣是 bool
low < node.val < highPython 可以連寫,等於 low < node.val and node.val < high。用 < 不是 <=,相等不合法
and左右兩邊都 True 才 True。左邊 False 就不跑右邊
float("-inf")負無限大,比任何數字都小。root 上面沒有人,所以沒有限制
return dfs(...)外層要把 dfs 的答案交出去,少了這個 return 會交回 None

def dfs(node, low, high):
    if not node:
        return True
說"If the node is out of range, stop. Otherwise, check both sides with tighter bounds."
    if not (low < node.val < high):
        return False
    return dfs(node.left, low, node.val) and dfs(node.right, node.val, high)
說"The root has no limits, so I start with negative and positive infinity."
