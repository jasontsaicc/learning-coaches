路上的最大值

Count Good Nodes in Binary Tree。前序模板只多一個參數:往下走時,把「這條路目前最大值」交給小孩。

01這題在幹嘛

從 root 走到某個 node,如果路上沒有人比它大,它就是 good。數有幾個 good node。

02這是什麼型

  • 1題目講「從 root 到 X 的路上」:答案跟祖先有關 → 由上往下走,前序(先處理自己,再交給小孩)。
  • 2每站只需要知道路上的一個數字(最大值),不需要整條路 → 把它當 dfs 的參數往下傳。
  • 3跟你剛默的前序模板比:dfs(node) 變成 dfs(node, max_so_far),append 前面多一個 if。

03暴力法,為什麼慢

每到一個 node,就從 root 重新走一次到它,看路上有沒有比它大的。

暴力(每站重走一次路)往下傳 max
每站做什麼重看整條路,h 個數字只比 1 次
時間O(n · h)O(n)
空間O(h)O(h) call stack

暴力法浪費的事:爸爸已經看過整條路了。爸爸把「路上最大值」直接交給小孩,小孩就不用回頭看。

完整 code 加逐行解釋先自己寫,卡住再開 
def goodNodes(self, root):
    res = []                                   # 裝 good node(跟前序模板一樣)

    def dfs(node, max_so_far):                # 多一個參數:路上目前最大
        if not node:
            return
        if node.val >= max_so_far:             # ① 判斷自己            res.append(node.val)        new_max = max(max_so_far, node.val)    # ② 算要交給小孩的        dfs(node.left, new_max)
        dfs(node.right, new_max)

    dfs(root, root.val)                        # 起點:root 自己就是第一個 max
    return len(res)
行做什麼
>=寫成 >:等於的不算 good,例子裡左下的 3 會漏掉
new_max是 local 變數,每個 frame 一份。frame return,它就消失
dfs(root, root.val)題目保證至少 1 個 node。也可以用 float("-inf")
len(res)只要數量。也可以用 count 加 nonlocal,那是新語法,今天先不用

螢光的 3 行就是跟前序模板的差別。其他行都是你剛默寫的。

模板:前序 + 往下傳值 = dfs(node, 從上面帶來的東西)。同一招也用在 Path Sum(#112,往下傳剩下的和)、Validate BST(#98,往下傳上下界)。

複雜度
時間O(n):每個 node 進一次
空間O(h):call stack;res 最多 n,換成 count 就 O(1)
L6 面試逐字稿

MOVE 0先問 constraint

說"Does a node with the same value as the max count as good? Can values be negative? Is the tree ever empty?"

想相等決定 >=;負數決定起點不能用 0;不會空決定可以用 root.val 起跑。

MOVE 1舉例

說"Let me use this tree: 3, 1, 4, 3, null, 1, 5. The good nodes are 3, 3, 4, and 5, so the answer is 4."

寫畫 01 那棵樹,圈 4 個 good。

MOVE 2暴力解 20 秒

說"The brute force is to check the whole path again for every node. That is O(n times h)."

MOVE 3Invariant

說"Each call gets the max value on the path from the root to its parent. So one comparison tells me if this node is good."

想這句證明「只看一個數字就夠」。

MOVE 4關鍵手法換了什麼

說"Instead of looking back up the path, I pass the max down as a parameter. Each path keeps its own copy, so the left side never affects the right side."

MOVE 5複雜度先講

說"This is O(n) time because I visit each node once, and O(h) space for the call stack. Sound good?"

MOVE 6code 分 3 段

說"It's a preorder DFS with one extra parameter."
def dfs(node, max_so_far):
    if not node:
        return
說"First I check the current node, then I update the max for the children."
    if node.val >= max_so_far:
        res.append(node.val)
    new_max = max(max_so_far, node.val)
    dfs(node.left, new_max)
    dfs(node.right, new_max)
說"I start from the root with its own value."
dfs(root, root.val)
return len(res)

MOVE 7主動 dry run

說"At 1, the max is 3, so it's not good. At 4, the max is still 3, because the left side doesn't change it. So 4 is good, and it passes 4 down to its children."

MOVE 8主動掃 edge case

說"With negative values, starting from zero would be wrong, so I start from root's value instead. A single node returns 1."

MOVE 9推廣

說"The same pattern works for Path Sum and Validate BST. I just pass a different value down."
