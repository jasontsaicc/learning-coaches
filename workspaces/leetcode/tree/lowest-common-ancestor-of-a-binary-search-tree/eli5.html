BST 分叉點

Lowest Common Ancestor of a Binary Search Tree。每一站只比一次大小,p 和 q 分開走的那一站就是答案。

01這題在幹嘛

樹上有兩個 node p 和 q。從 root 往下走,兩條路一開始重疊,在某一站分開。兩條路最後一個一樣的站就是答案。

路經過的站
到 p = 15 → 3 → 1
到 q = 45 → 3 → 4
最後一個一樣的站3

02這是什麼型

  • 1題目寫 BST:每個 node 都是「左邊全部 < node.val < 右邊全部」。看到 BST 就問:能不能每站比一次大小,只走一邊?
  • 2題目要找兩個 node 的共同祖先(LCA)。
  • 3題目說 node 可以是自己的祖先:p 剛好就是那一站時,答案就是 p。

03暴力法,為什麼慢

不管 BST 規則:先從 root 找出到 p 的整條路,存成 list;再找到 q 的整條路;最後從頭比兩個 list,最後一個一樣的就是答案。

暴力(當普通樹)用 BST 規則
找一個 node不知道往哪,左右都要找比一次大小就知道往哪
時間O(n)O(h)
空間O(h) 存兩條路O(1) 只有 node

暴力法浪費的情報:BST 已經幫你排好序了。

完整 code 加逐行解釋你 10/08 自己寫出來的 
def lowestCommonAncestor(self, root, p, q):
    node = root                                    # 出發點:我現在站在哪
    while node:
        if p.val < node.val and q.val < node.val:  # 都比我小
            node = node.left
        elif p.val > node.val and q.val > node.val:  # 都比我大
            node = node.right
        else:                                      # 分邊,或相等
            return node
