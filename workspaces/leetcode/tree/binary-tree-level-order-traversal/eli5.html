LeetCode #102 · Tree · BFS 首刷(龜模式)

一層一層排隊

Binary Tree Level Order Traversal。你已經會 DFS 一條路走到底。今天換一種走法:一層走完才下一層。

01這題在幹嘛

從上到下,一層一層把 node 的值拿出來。同一層從左到右,每一層裝成一個 list。

答案:[[3], [9, 20], [15, 7]]。灰色虛線框是 None,它們不是 node,不會出現在答案裡。

02這是什麼型

BFS(Breadth-First Search,廣度優先),工具是 queue(排隊)。

  • 1題目出現「level / 層 / 每一層」:每層的平均、每層最右邊那個、之字形走。
  • 2題目問「最短 / 最近 / 最少幾步」:一層一層往外擴,第一次碰到就是最近的。
  • 3答案的形狀是 list 裡面裝 list,一格一層。

跟你 9/21 寫的 DFS 前序比一比

DFS 前序(你會的)BFS 一層一層(今天)

03用你會的前序,為什麼不行

換一棵滿樹 [1,2,3,4,5,6,7]。圓圈裡的數字是「第幾個被拿到」。

前序(DFS)拿到的順序

拿到:1 2 4 5 3 6 7。4 比 3 早,跨層了。

這題要的順序

要的:1 | 2 3 | 4 5 6 7。一層拿完才下一層。

暴力法:一層跑一次 DFS

先算樹有幾層。然後「只收第 0 層」跑一次 DFS、「只收第 1 層」再跑一次……每次都從 root 重走整棵樹。 n 個 node、h 層,總共 O(n × h)。樹歪成一條鏈時 h = n,變成 O(n²)。

浪費的免費情報:站在 node 2 的時候,你已經知道 4 和 5 是「下一層」。暴力法把這個情報丟掉,之後再從 root 走一次去找。

04做法:看 q 裡面裝什麼

      3          第 0 層
     / \
    9   20       第 1 層
       /  \
      15   7     第 2 層

q 是一個 list,裡面放還沒處理的 node。每一步只做一件事:從左邊拿一個出來,把它的小孩加到右邊。None 不加。

q = [3]
拿 3,加 9、20     →  q = [9, 20]     ← 剛好是第 1 層
拿 9,沒有小孩     →  q = [20]
拿 20,加 15、7    →  q = [15, 7]     ← 剛好是第 2 層
拿 15,沒有小孩    →  q = [7]
拿 7,沒有小孩     →  q = []          停

拿出來的順序是 3 9 20 15 7,剛好一層一層、由左到右。

還差一步

這樣只得到一條 [3, 9, 20, 15, 7](已跑 code 驗證)。題目要分層:[[3], [9, 20], [15, 7]]。

q = [9, 20] 的時候,這一層要拿幾個?你怎麼知道?

答案:每層開始前先記下 len(q)想好了再展開 
q = [3]        len(q) = 1 → 拿 1 個:3        加 9、20  →  level = [3]
q = [9, 20]    len(q) = 2 → 拿 2 個:9、20    加 15、7  →  level = [9, 20]
q = [15, 7]    len(q) = 2 → 拿 2 個:15、7              →  level = [15, 7]
q = []         停

每一層開始的那一刻,q 裡剛好只有這一層的 node。先把 len(q) 記下來,只拿這麼多個。

拿 20 的時候 15、7 被加進 q,但這一層已經說好只拿 2 個,所以 15、7 留到下一層。

不記 len(q) 會一直拿到 q 空掉,全部混成一層:[[3, 9, 20, 15, 7]]。

完整 code 加逐行解釋想好了再展開 
from collections import deque

class Solution:
    def levelOrder(self, root):
        if not root:                         # ① 空樹直接交 []
            return []
        res = []                             # ② 收答案(外殼 a)
        q = deque([root])                    # ③ q 先放 root
        while q:                             # ④ 一圈 = 一層            level = []                       # ⑤ 這一層的小 list
            for _ in range(len(q)):          # ⑥ 這一層有幾個                node = q.popleft()           # ⑦ 從前面拿
                level.append(node.val)
                if node.left:                # ⑧ None 不排隊
                    q.append(node.left)      #    小孩排隊尾
                if node.right:
                    q.append(node.right)
            res.append(level)                # ⑨ 一層收完,交給 res
        return res                           # ⑩ 交答案(外殼 d)
行做什麼拿掉會怎樣
①空樹擋在門口q 變成 [None],拿出來讀 .val,AttributeError
③deque 是兩頭都能快速進出的 list用 list 的 pop(0) 也對,但每次要把後面全部往前挪一格,O(n)
④q 還有 node 就繼續
⑥len(q) 只在 for 開始時算一次。之後排進來的人不影響這個數字分層消失,全部混成一層
⑦popleft = 從前面拿(先來先拿)改成 pop() 會從後面拿,變成 stack,走法變 DFS
⑧只加真的 nodeNone 進 q,之後讀 .val 就掛
⑨縮排在 while 裡、for 外面縮進 for 裡:每拿一個人就交一次

外殼對照:DFS 是「res、內層 def、啟動、return res」四格。BFS 只有三格:res、while 迴圈、return res。沒有內層函式,也沒有啟動那一行,因為 while 自己就在跑。

MOVE 2暴力解 20 秒

說A brute-force way is to run a DFS once per depth and keep only the nodes at that depth. That's O(n times h). It throws away free information: when I visit a node, I already know its children belong to the next level.

MOVE 3Invariant

說At the start of each round of the while loop, the queue holds exactly one full level, in left-to-right order. So if I take out exactly len(queue) nodes, I get that level and nothing else.
想這句話同時說明了兩件事:為什麼要先記 len(q)(分層),為什麼用 queue(左到右)。

MOVE 4關鍵手法和它換掉了什麼

說The key tools are a FIFO queue and a level-size snapshot. The queue gives me left-to-right order for free, and the snapshot draws the line between this level and the next. I pay O(width) extra memory to get a single pass.

MOVE 5複雜度,寫 code 之前講

說Each node goes into the queue once and comes out once, so time is O(n). The queue holds at most one level, which can be about n over 2 nodes, so space is O(n) in the worst case. Sound reasonable?

MOVE 7主動 dry run(Move 1 的例子)

說Let me run my example. Round one: the queue is [3], size one. I pop 3 and push 9 and 20. Level is [3]. Round two: size two. I pop 9, no children, then 20, and push 15 and 7. Level is [9, 20]. Round three: size two, I pop 15 and 7. The queue is empty, so I stop.

MOVE 8主動掃 edge case

說Empty tree: the guard returns an empty list. One node: one round, [[1]]. A tree that's just a line: every level has size one, and it still works. Nodes on the same level with different parents: they sit next to each other in the queue, so they land in the same list without extra code.

MOVE 9推廣

說The same template solves right side view: I keep only the last value of each level. For zigzag, I reverse every other level. For minimum depth, I return as soon as I pop the first leaf. On a general graph, I'd also need a visited set, because a graph can have cycles and a tree can't.

完整 code 和「哪句話對應哪幾行」

def levelOrder(self, root):
    if not root:                 # A
        return []
    res = []
    q = deque([root])            # A
    while q:                     # B
        level = []
        for _ in range(len(q)):  # B, C
            node = q.popleft()   # D
            level.append(node.val)
            if node.left:  q.append(node.left)    # D
            if node.right: q.append(node.right)   # D
        res.append(level)
    return res
