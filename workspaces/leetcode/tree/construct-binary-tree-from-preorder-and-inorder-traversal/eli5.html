LAYER 1

這是什麼型

讀 2 分鐘

遞迴切兩半:找到 root,把兩個 list 切成左右,每一邊做同一件事。

  • 題目給兩種走訪的 list,要你交回 root。

LAYER 3

複雜度

讀 2 分鐘

切片版好懂但最慢 O(n²)。hash map 版省掉「找位置」和「複製 list」,變 O(n)。

切片版hash map 版
找 root 位置index,O(n)pos[val],O(1)
切 list每層複製,O(n)不複製,只傳 lo、hi
時間樹平衡 O(n log n),一條鏈 O(n²)O(n)
空間一條鏈 O(n²)O(n)

面試順序:先寫切片版,講完複雜度,再說怎麼優化成 hash map 版。

hash map 版 code速刷可跳過 
def buildTree(self, preorder, inorder):
    pos = {val: i for i, val in enumerate(inorder)}
    next_root = 0

    def dfs(lo, hi):
        nonlocal next_root
        if lo > hi:
            return None
        root = TreeNode(preorder[next_root])
        next_root += 1
        mid = pos[root.val]
        root.left = dfs(lo, mid - 1)
        root.right = dfs(mid + 1, hi)
        return root

    return dfs(0, len(inorder) - 1)

這裡 mid 是整條 inorder 的位置,不再等於左子樹個數。前序靠 next_root 往前走:先蓋完整棵左子樹,next_root 就剛好指到右子樹的 root,所以一定要先蓋左邊。

LAYER 6

你最可能犯的錯

讀 2 分鐘

最容易錯的是前序的左子樹切片少 + 1。

切片少 + 1preorder[1:mid],mid = 1 時是 [1:1] = [],9 就不見了。起點是 1,要拿 mid 個,所以終點是 mid + 1。
呼叫少 self.寫成 buildTree(...) 會 NameError。它是方法,要寫 self.buildTree(...)。
拿 node 去找inorder.index(root) 會 ValueError。list 裡放的是數字,root 是 TreeNode,要找 preorder[0]。
漏 return root這層蓋好了卻沒交回,上一層的 root.left 收到 None,整棵樹接不起來。
漏 base case空 list 跑 preorder[0] 會 IndexError。

Edge cases

情況mid靠什麼答對
只有 1 個 node0左右都切出空 list,base case 接住
沒有左子樹0preorder[1:1] 和 inorder[:0] 都是空的
沒有右子樹n - 1[mid + 1:] 超過尾巴,切片交回空 list,不會報錯

模板切片版 
def build(pre, ino):
    if not pre:
        return None
    root = TreeNode(pre[0])                       # 找 root
    mid = ino.index(pre[0])                       # 數左邊
    root.left = build(pre[1:mid + 1], ino[:mid])  # 切左邊
    root.right = build(pre[mid + 1:], ino[mid + 1:])  # 切右邊
    return root
