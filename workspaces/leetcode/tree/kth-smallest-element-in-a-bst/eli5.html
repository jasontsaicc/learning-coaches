def kthSmallest(self, root, k):
    res = []                                  # 外層:收值的 list

    def dfs(node):
        if not node:
            return                            # 空的,什麼都不收
        dfs(node.left)                        # ① 先往左
        res.append(node.val)                  # ② 收我(夾在中間 = 中序)        dfs(node.right)                       # ③ 再往右

    dfs(root)                                 # 啟動
    return res[k - 1]                         # 第 k 個 = index k-1
行做什麼
res = []放在外層。內層 dfs 每一站都往同一個 list 加
return內層 dfs 不交回值,只負責把值收進 res。所以這裡空的 return 就好
append 夾在中間放上面是前序、放下面是後序。夾在兩個呼叫中間才是中序,收出來才排好
dfs(root)不寫這行,說明書寫好了沒人執行,res 永遠是 []
res[k - 1]題目從 1 數,Python 從 0 數

Follow-up:收到第 k 個就停(今天不寫)

上面的版本會把整棵走完。k = 1 只要最左邊那一個,後面都白走。收滿 k 個就不再往下:

def dfs(node):
    if not node or len(res) == k:         # 收滿了,不再走        return
    dfs(node.left)
    if len(res) == k:                      # 左邊回來時可能已經收滿        return
    res.append(node.val)
    dfs(node.right)

時間從 O(n) 變 O(h + k):先往左鑽到底花 h 步,再收 k 個。

L6 面試逐字稿

MOVE 0先問 constraint

說"Is k always valid, between 1 and n? Is k 1-indexed? Will this be called many times on a tree that changes?"

想k 一定合法就不用處理越界;1-indexed 決定 k - 1;一直被呼叫又會改樹,就是 follow-up(每個 node 記子樹大小)。

MOVE 1舉例

說"Let me use 5, 3, 6, 2, 4, null, null, 1 with k equals 3. Sorted, the values are 1 through 6, so the answer is 3."

寫畫 01 那棵樹,下面寫 1 2 3 4 5 6,圈 3。

MOVE 2暴力解 20 秒

說"I could collect all values, sort them, and take index k minus 1. That's O(n log n), and it ignores the BST order."

MOVE 3Invariant

說"In a BST, an inorder traversal visits values in sorted order. Everything on the left is smaller, then the node, then everything on the right is larger."

想這句就是「不用 sort」的理由。

MOVE 4關鍵手法換了什麼

說"So I do a normal inorder traversal into a list. The k-th visited value is the answer."

MOVE 5複雜度先講

說"That's O(n) time and O(n) space for the list. I can stop early after k values, which makes it O(h plus k). Sound reasonable?"

MOVE 6code 分 3 段

說"I keep a result list outside the helper."
res = []
說"The helper goes left, adds the current value, then goes right."
def dfs(node):
    if not node:
        return
    dfs(node.left)
    res.append(node.val)
    dfs(node.right)
說"I run it from the root and return index k minus 1, because k starts at 1."
dfs(root)
return res[k - 1]

MOVE 7主動 dry run

說"From 5 I go left to 3, 2, then 1. 1 has no left child, so I add 1. Back at 2, I add 2. Back at 3, I add 3. Now the list has three values, and the answer is 3."

MOVE 8主動掃 edge case

說"k equals 1 gives the leftmost node. k equals n gives the rightmost. A tree that is one long chain still works, but the call stack gets n deep."

MOVE 9推廣

說"If the tree changes often and we ask a lot, I'd store the size of each subtree in every node. Then I can pick left or right at each step, like binary search, in O(h)."
