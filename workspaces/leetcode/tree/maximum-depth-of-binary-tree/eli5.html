等下屬回報的深度

Maximum Depth of Binary Tree。#226 你只要交代下去就好，這題開始你必須等下屬回報完才能算自己的答案。

01這題在幹嘛

給你一棵樹，問「從根走到最遠的葉子，一共踩過幾個節點」。

注意數的是節點數，不是邊數。所以只有一顆節點的樹，深度是 1 不是 0。空樹才是 0。

02這是什麼型，怎麼秒認

Tree DFS，而且是「後序」那一款：先把兩邊問完，再算自己。

  • 01題目問的是整棵樹的某個總量（深度、節點數、直徑、是否平衡）。總量沒辦法只看一格就知道。
  • 02「這一格的答案」可以用左邊答案 + 右邊答案算出來。這句話成立，就是遞迴題。
  • 03你想不出不用遞迴要怎麼寫。這是好事，不是壞事。

03不用遞迴的話會長怎樣

你可以一層一層剝：先收集第 1 層所有節點，再收集第 2 層，數剝了幾次。這叫 BFS。

BFS 一層一層剝

# 手上要維護一個 queue
層 1: [1]        depth=1
層 2: [2, 3]     depth=2
層 3: [4]        depth=3
層 4: []         停

會動，也是 O(n)。但你要自己管一個 queue、自己記層數、自己判斷什麼時候算「一層結束」。

遞迴

# 不用 queue,不用記層數
return max(左, 右) + 1

層數是 call stack 自己幫你記的。你每往下一層，Python 就替你多疊一張便條紙。

所以遞迴省的不是時間，是帳。兩邊都是 O(n)。遞迴把「現在在第幾層」這本帳外包給 call stack，你只要寫「這一層怎麼算」。這是遞迴唯一的賣點，記住這句話比記 code 有用。

04call stack 到底長什麼樣（無 code，純圖）

先把兩件看不見的東西畫出來，因為它們是卡點的來源。

看不見的東西 ①：None 子節點是真的存在的

樹圖通常只畫有值的格子。但 2 的右邊、4 的兩邊，欄位不是「不存在」，是存著 None。遞迴會真的走進去，然後撞到煞車。

看不見的東西 ②：return 做的是兩件事

第 ① 件　把值放到交接口，交給呼叫我的那張紙。
第 ② 件　把我這張便條紙撕掉。紙上的 node / left / right 全部消失。控制權倒退回呼叫我的那一張，而且是從它當初卡住的那一行接著跑。

大部分人卡在第 ② 件。return 不是「跳到某個地方」，是倒退。誰呼叫你，你就退回誰那裡，沒有第二個選項。

整齣戲只有兩種動作

疊一張紙（呼叫）、撕一張紙（return）。疊的時候什麼都算不出來，所有的數字都是在「撕」的那一刻產生的。所以樹是「先一路衝到底，再一層一層往回算」。往下叫做委派，往回叫做回報。

為什麼順序不能改

你不能先寫 return max(left, right) + 1 再寫 left = ...。因為 return 會當場撕紙，後面的行永遠不會執行。這就是 #226 「擺哪都行」和 #104 「只能擺最後」的差別。

05自己先試，再打開

完整 code + 逐行解釋先自己在 drill.py 打一次 
def maxDepth(self, root):
    # 1. 煞車:走到空的地方,深度 0。回傳「數字」是因為上一層要拿它算 max
    if not root:
        return 0

    # 2. 委派:兩邊都要問。問完才有資格比大小
    left  = self.maxDepth(root.left)
    right = self.maxDepth(root.right)

    # 3. 組裝:兩邊挑深的那一邊,+1 是算「我自己這一層」
    return max(left, right) + 1
片段它在幹嘛拿掉會怎樣
if not root遞迴的煞車無限遞迴 → RecursionError
return 0空樹深度定義上一層 max(None,…) 直接 TypeError
left = …問左邊那一支多深漏算整條左子樹
right = …問右邊那一支多深漏算整條右子樹
max(…)取比較深的那邊換成 min 會回「最淺」，換成 + 會變節點數
+ 1算自己這一格整棵樹永遠回 0

複雜度：每個節點剛好被拜訪一次，O(n) 時間。空間是 O(h)，h 是樹高，也就是 call stack 最厚的時候有幾張紙。歪斜樹最糟 O(n)。

口訣 + 可重複使用的模板下一題直接套
先問兩邊，再算自己。+1 是你自己那一層。

三格模板，四題共用，只有格子的內容換：

def dfs(node):
    if not node:
        return <煞車值>        # 由「上一層要拿它算什麼」決定
    left  = dfs(node.left)
    right = dfs(node.right)
    return <組裝式>            # 用 left / right 算出自己這層
題煞車值組裝式
#104 Max Depth0max(left, right) + 1
#226 InvertNone（不吃回傳值，交換後 return node）
#100 Same TreeTrueleft and right
#543 Diameter0max(left,right)+1，另記全域 left+right

煞車值的判準句：base case 回傳什麼，不是你決定的，是上一層要拿它來算什麼決定的。要比大小就回 0，要做 and 就回 True。

MOVE 0先問 constraint，手不碰白板

Say"Before I start — a few quick questions. Can the tree be empty? How deep can it get, roughly? Am I counting nodes or edges on the path? And is it a plain binary tree, or a BST?"
Think「數節點還是數邊」是這題唯一真的會扣分的歧義。深度上限問出來，Move 5 才能談要不要改 iterative。

MOVE 1重述 + 自己舉例

Say"So: return the number of nodes on the longest root-to-leaf path. Let me draw one I'll reuse later — root 1, left child 2, right child 3, and 2 has a left child 4. The longest path is 1 to 2 to 4, so the answer is 3."
Think自己舉例是為了 Move 7 的 dry run 有東西可以指，不是為了表演。不對稱的例子（右邊比左邊淺）才能證明你沒有隨便選一邊。

MOVE 2暴力解 20 秒，指出它浪費什麼

Say"The brute-force way is BFS: peel the tree one level at a time and count the peels. It's also O(n), so it isn't slower — but I'd be hand-rolling a queue and tracking level boundaries myself. The recursive version gets that bookkeeping for free from the call stack."
Think誠實說「不是比較快」比硬掰快很多分。把賣點講準：省的是 bookkeeping〔記帳〕，不是時間。

MOVE 3講 invariant

Say"The invariant is: dfs(node) returns the depth of the subtree rooted at that node, and nothing else. If I trust that for both children, then my own answer is just the deeper child plus one for myself. Empty subtree has depth zero, which makes it bottom out."
Think這是全場最重要的一句。invariant 說得清楚，面試官就不會叫你證明遞迴會停。"trust that for both children"〔相信兩個下屬都做對了〕是遞迴的標準說法。

MOVE 4關鍵手法，換掉了什麼

Say"I'm going bottom-up: each node waits on both children before it can answer. That trades stack space for code I don't have to write. It costs O(h) — if the interviewer cares about a skewed tree, I'd swap to an explicit stack."

MOVE 5複雜度講在寫 code 之前

Say"O(n) time, since every node is visited exactly once. O(h) space for the recursion stack, worst case O(n) on a skewed tree. Sound reasonable?"
Think"Sound reasonable?" 是給面試官一個踩煞車的機會。先設計、對齊，再動手。

MOVE 6code 分三段寫，每段一句話

Say"First the base case — an empty node has depth zero, and that's what stops the recursion."
if not root:
    return 0
Say"Then I ask both children. I have to ask both — I can't guess which side is deeper."
left  = self.maxDepth(root.left)
right = self.maxDepth(root.right)
Say"And I take the deeper one and add one for myself."
return max(left, right) + 1

MOVE 7主動 dry run，用 Move 1 那個例子

Say"Let me walk my example. dfs(4) sees two empty children, returns 1. dfs(2) gets 1 from the left, 0 from the right, returns 2. dfs(3) returns 1. So the root does max of 2 and 1, plus one, which is 3. Matches."
Think不用等面試官說「跑一下」。主動 dry run 換到的是「這個人自己會驗」。

MOVE 8主動掃 edge case，點名誰負責

Say"Empty tree returns 0 — the base case handles it directly. Single node returns 1. A skewed tree with only left children still works, because I always ask both sides instead of picking one."

MOVE 9主動講推廣

Say"This same shape generalizes. Same Tree swaps the combine step for a logical and; Diameter keeps this return value but also tracks left plus right in a global max; Balanced Binary Tree returns a sentinel to short-circuit. It's one template with the base value and the combine step swapped out."
ThinkMove 9 是「解一類，不是解一題」的證據。講得出模板遷移，面試官就知道你不是背這一題。
